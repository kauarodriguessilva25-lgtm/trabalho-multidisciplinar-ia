-Solução e Propostas de Guardrails
Desenvolvimento de diretrizes éticas e técnicas de bloqueio aplicadas a prompts de sistema para limitar a atuação de IAs generativas:
- Guardrail 1 (Privacidade): Bloqueio de processamento de PII sem consentimento direto.
- Guardrail 2 (Dignidade): Proibição de geração de conteúdos difamatórios ou humilhantes.
- Guardrail 3 (Interrupção de Fluxo): Cancelamento imediato de execução ao receber dados brutos de monitoramento não autorizados.
